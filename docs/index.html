How to check on your phone

Fastest test: open the phone dialler and enter *#06#. If an EID number appears, the device has eSIM hardware. It also needs to be unlocked to use another provider's eSIM.

iPhone: Settings → General → About shows your model. Under Carrier Lock, “No SIM restrictions” means it is unlocked. Then check Settings → Mobile Data (or Cellular) for Add eSIM.

Samsung Galaxy: Settings → About phone shows the model. Then Settings → Connections → SIM manager → Add eSIM.

Google Pixel: Settings → About phone shows the model. Then Settings → Network & internet → SIMs to add an eSIM.

Tablets and Windows laptops: you need a cellular (eSIM-capable) version. On Windows, open Settings → Network & internet → Cellular and look for eSIM profiles.

Menu names vary by software version. Don't delete an existing eSIM to test compatibility. Phones bought in mainland China, Hong Kong or Macao may differ, so check the exact model number.
